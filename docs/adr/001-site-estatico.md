# ADR 001: Site estático com HTML/CSS/JS

Data: 2026-09-22
Status: Aceito

## Contexto
Projeto portfólio do Studio Lídia Siqueira, precisa ser simples de hospedar e manter.

## Decisão
Usar site 100% estático (index.html + style.css + script.js), sem backend, hospedado no GitHub Pages.

## Consequências
- Positivas: grátis, rápido, fácil de manter, CI simples.
- Negativas: sem banco de dados; agendamento via link do WhatsApp.
